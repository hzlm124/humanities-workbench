# 09 · 覆盖表与维度扫描

一张研究计划只能覆盖作者想到的东西。覆盖表的作用不是「更全面」，而是让**空白变成声明**，而不是疏忽。

## 一 · 覆盖表（计划必带）

在 `00-plan.md` 里画一张表：行 = 问题的构成单元，列 = 卡片编号。

```
| 单元 \ 卡片 | C01 | C02 | C03 | 说明 |
|---|---|---|---|---|
| 子问题：财政如何支撑 | ✓ |   |   | 由 C01 承担 |
| 行动者：地方士绅 |   | ✓ |   |   |
| 行动者：驻军 |   |   | gap | 无材料，声明缺口 |
| 时期：1949–1953 | ✓ | ✓ |   |   |
| 维度：性别 |   |   | gap | 本问题范围内次要，声明 |
```

规则：
- 每个空格要么打勾，要么写 `gap`（并注明为什么现在不查）。
- 一个维度没有材料支撑 ≠ 它不重要；写「查过，材料缺失」和「未查」是两回事。
- 表要能一眼看出「谁在承担哪一格」。

## 二 · 七个扫描轴

切问题之前，沿这七条各写一行。哪一条写出空白，就往那里补卡或补声明。

1. **学科**：哪些领域会研究这个对象？相邻领域会怎么问？（经济史 / 社会史 / 思想史 / 军事史 / 科技史 / 人类学 / 政治学 / 法学 / 地理）
2. **时期**：为什么从这个时点开始、到这个时点结束？前后各一段是否改变结论？
3. **地理与尺度**：国家 / 区域 / 城市 / 村落 / 帝国 / 海域 / 全球链条。换尺度会看到什么？
4. **行动者**：决策者、执行者、承受者、旁观者、反对者、外部力量。谁被当作默认主体？
5. **材料类型**：档案、统计、报刊、私人书信、口述、图像、地图、物质遗存、文学、法律文本。哪一类完全没碰？
6. **方法**：过程追踪、比较历史、量化、话语分析、概念史、网络分析、微观史。方法盲区会带来证据盲区。
7. **问题类型**：机制（怎么发生）、起源（为何此时）、功能（维持了什么）、意义（当时人如何理解）、后果（谁付出代价）。哪一类没问？

## 三 · 扫描不是打勾

- 一个维度若与本问题没有实质联系，写「无实质联系」并说明，而不是硬造一张卡。
- 两个轴互相冲突时（例如「全球尺度」与「村落尺度」给出不同答案），**冲突本身常常就是研究问题**。
- 学科分类是别人对知识的组织方式，不是世界的结构。用它找盲区，不要用它切问题。

## 四 · 什么时候重扫

- 计划阶段：一次。
- 红队阶段：一次（专门找被漏掉的行动者、时期、后果）。
- 出现「结论太顺」的时候：一次。太顺通常意味着覆盖表太整齐。

## 五 · 输出片段（贴进计划末尾）

```
## Coverage check
扫描轴：学科/时期/地理/行动者/材料/方法/问题类型
已覆盖：<逐条>
声明缺口：<逐条 + 为什么不查 + 什么条件下要回来查>
未扫描及原因：<逐条>
本计划的停止条件：<什么情况下算查够>
```
