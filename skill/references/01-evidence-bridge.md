# 01 · 证据桥接与史料批判

> 材料 ——[最弱充分前提]→ 当前理解

一切研究争议最终都落在同一处：**为什么这份材料支持这个理解？**
把那个前提说出来，说到最弱仍然够用。不要画整张论证图，只画真正承重的那一跳。

## 1. 桥的四种形状

| 形状 | 你要说的话 | 失败长相 |
|---|---|---|
| 归纳 | 这些案例共有的机制是 M，样本覆盖 A/B/C 三类情形 | 只列同向案例，反例被「特殊情况」吸收 |
| 因果 | X 在 T 时点改变了 Y 的约束集，机制是 M | 相关替代机制；把事后叙事当机制 |
| 概念 | 在此语境中 T 指 X 而非现代的 X'，证据是同时代用法 | 用今天的词义读旧文本 |
| 结构 | 材料的排布方式本身说明 R（谁在前、谁被略去） | 排布只是编辑偶然，却当成作者意图 |

## 2. 证据负担随分量上升

- **搜索摘要、百科、二手概述**只用于发现线索，不能承载关键事实。
  决定性事实必须回到原始记录，或回到制度上最有资格知道它的那一层（档案馆、统计年鉴、会议记录）。
- **引文、数字、日期、人名、文献是否存在**：给精确位置。原件不可得就下调断言，不要把中介层洗成原话。
  「某书说某书说」不是引文。
- **区分材料陈述 / 你的推断 / 作者判断**，三种句子不要合写。判断段里出现「显然」「自然」时尤其要检查。
- **转述不构成独立印证**：三次转述同源 = 一个来源。三条独立来源才能说是共识，而共识是关于文献的事实，不是关于世界的事实。
- **OCR / 翻译 / 转录 / 计算 / 编辑**承重时，保留转换的边界与不确定：哪个版本、谁译的、缺了哪几页。
- **缺席只有在该记录系统本应留下痕迹时才是反证**。
  先立住「若 P 为真，这套记录会不会产生并保存这份痕迹」，再谈沉默。
  例：某次会议无记录——若会议本身无记录制度，沉默无信息；若有逐日档且同期其他会议齐全，沉默才有分量。

## 3. 来源层级（不是等级崇拜，是距离）

```
L0 原件/档案/同期一手（未刊档案、会议记录、统计原表、当事人日记、照片、地图）
L1 同期公开出版物（报刊、官报、年鉴、议会记录、企业年报）
L2 学术专著与经同行评议的论文（含其注释里的档案引用——顺着注释走，往往比正文有用）
L3 综述、百科、教科书、数据库条目
L4 媒体、博客、论坛、模型记忆
```

用途分工：L3/L4 用来**找词、找线索、找争论的名字**；L0/L1 用来**定事实**；L2 用来**定解释与争论状态**。
用 L2 的注释当索引去 L0 找原件，是本工作台最高效的一条路径。

## 4. 史料批判四问（对每一份关键材料）

1. **它是什么**：文书类型、作者位置、写作场合、给谁看、有没有被审查/自我审查的可能。
2. **它怎么来的**：原始记录、事后回忆、口述、翻译、编纂、还是数据库二次加工？中间断了几道？
3. **它想干什么**：说服、备案、邀功、脱责、募款、宣传、存档义务。目的的差异会改变它记录什么、漏掉什么。
4. **它在体系里的位置**：同批档案的其他卷、同期的另一套记录、敌对一方的记载，说的是同一件事吗？
   两边都记载且细节冲突时，冲突本身通常是发现（谁有能力知道什么、谁有动机改什么）。

## 5. 反证优先于支持

每张研究卡开工时先写**证伪条件**：什么材料出现会让我放弃当前工作前提。
然后**主动去搜那个材料**，而不是搜支持。前提变了就更新证伪条件，不要每次搜索前重复同一套仪式。

## 6. 断言的强度刻度

写结论时给每条断言标一档，别用「可能」「或许」含混过去：

- `established`：多源一手，位置齐备，无已知反证
- `probable`：一手单一来源，或二手共识且有档案引用链
- `contested`：存在同等强度的对立记载（写明双方）
- `inferred`：从材料推出，材料本身没说
- `unknown`：查过，且该记录系统本应有痕迹（这才是「查无」）
- `unsearched`：还没查（绝不写成 unknown）

## 7. 交付格式（每条发现一行）

```
claim: <一句话，可被判真伪>
type: fact | inference | interpretation | normative
strength: established | probable | contested | inferred | unknown | unsearched
source: <作者/机关>《<题名>》(<版本/卷次>) <页/段/档号/行号>
locator: <URL 或档号> (访问 YYYY-MM-DD)
quote: "<原文，必要时双语>"
counter: <已知反证或对立记载；无则写 none found + 你搜过哪里>
```

这七行是全套技能的最小单位。任何研究报告、设定档案、反事实情景，最终都要能回落到这样的行。
