# 16 · 视频作为史料：工具链与可信度

视频（讲座、访谈、课程、UP 主的概念史讲解）是**线索来源**，不是**承重证据**。
它有口误、剪辑、无页码、无版本；但它能提供三样文字材料难给的东西：**问题意识、术语演变的通俗讲法、以及某派观点的自我表述**。

**选择理由**：你要的是「听懂概念史讲解」，核心是**文字**，不是画面。因此字幕/OCR/ASR 链路优先，
画面只用于读屏上文字（板书、图表、引文）。sense-now 的 `video_index` 正好按这个顺序设计，且证据带时间码可回溯。

## 2. 三路互校规则（吸收 video-watch-plus 的方法）

音频转写会幻觉。判定可信度只看三条的**交叉一致**：

```
优先级：官方/外挂字幕轨  >  屏显字幕 OCR（读像素，不编造）  >  ASR
冲突裁决：以画面文字为准（OCR 只读不改写；ASR 会补全、会重复、会造专名）
```

**B 站 AI 字幕的实测失真（2026-11-22，样本 BV1JHYZzFEgX）**：中文论证结构可用，但**外语术语几乎全错**——
希腊语 οὐσία 被转成「ESSD牙」，τί ἐστιν 成「5C雅」，εἶναι 成「A乃」，τὸ ὄν 成「抖on」，πολλαχῶς λέγεται 成「doom legdi」。
**规则**：字幕里的外语词、人名、书名一律视为占位符，必须回原文核对后才能写进档案；
可据语境推断原文（如「本质」一段对应 οὐσία / τί ἐστιν / τὸ ὄν），但推断结果要标 `inferred`，不得当引文。

**ASR 幻觉的典型特征**（出现即降级）：
- 同一短语循环重复（模型卡在循环里）；
- 时间轴跳跃或整段与画面无关；
- 专名错乱（人名、书名、术语被写成常见词）；
- 与屏显字幕/板书文字不符。

**硬规则**：
1. 无字幕且声学检测判断「无人声」→ 不得转写（宁可空着）。
2. ASR 结果只能标 `source_class = video-asr`，进入结论时必须写「据字幕/据转写」。
3. 转写里的**关键事实**（日期、数字、人名、著作）必须回到文字材料核对后才能承重。
4. 引用格式：`[mm:ss–mm:ss]` + 标题 + UP 主 + URL + 访问日期。

## 3. 从视频到概念史档案（接 15 册）

1. **建索引**：整片切块（sense-now 默认 5 分钟/块，带 20 秒重叠），得到 chunk catalog。
2. **只问不读全片**：先问「全片讲了哪几个概念、各自的时间段」；再对命中段 `query` 取原文。
3. **逐条记 W/R**：视频里的定义、词源、分期是「讲述者的说法」，标 `interpretation`；
   凡涉及具体年份、人物、著作，标 `unverified` 待查。
4. **回到文字**：用 15 册的六步流程，对视频提到的每个关键术语做真正的概念史（词典、原著、译本、研究）。
5. **产出**：概念史档案（15 册模板）+ 视频引用清单（带时间码）。

## 4. 成本控制

- 建索引是一次性成本，查询很便宜：**先索引，再问**，不要反复整片 OCR。
- 长片用后台 job；`job_status` / `job_resume` 支持断点续。
- 只在需要读屏上文字时才 `zoom` 取图；文字问题默认不带图。
- ASR 按需（`asr.mode=on_demand`）：先给计划（含 `planHash`），确认后才执行。

## 5. 记录模板

```
source: <标题> | <UP 主/讲者> | <URL> | 访问 YYYY-MM-DD
kind: video
source_class: video-sub | video-ocr | video-asr
evidence: [mm:ss–mm:ss] 原文
verified: 是/否（关键事实是否已回文字材料）
note: <这段提供的是问题意识 / 通俗讲法 / 某派自我表述>
```

## 6. 一句话纪律

**视频告诉你该去查什么，不告诉你事实是什么。**
