# 03 · 精读：四法 + 一句一注

精读不是摘要。摘要把文本压短，精读把文本**翻回它正在解决的问题**。
四种读法各有明确入口与产出；不要混着做，混着做就变成读后感。

## 通用装置：一句一注（Wager & Receipt）

读到承重句（删掉它，后面的结论垮掉的那句）时，写两行：

```
W（赌注）：作者在此赌了什么？这句话成立依赖哪个未言明的前提？
R（凭据）：我凭什么这么读？定位符（页/段/行/节）+ 我的推断链。
```

十句承重句的 W/R，胜过一份三千字综述。**没有 R 的 W 是投射，不是阅读。**

## 一 · 通览（overview）

要回答三件事，而不是解释任何一句：作者在回答什么问题、文本凭什么有资格这样回答、只读一小时的读者应从哪进。

1. 文本类型与读者：讲义、书信、专著、剧本、奏折、白皮书——类型决定什么算它的论证。
2. 标题、开头、结尾。开头常**制造困难**，结尾常**收窄承诺**：作者最终愿意主张到哪一步？两处是否一致？
3. 结构（目录/小标题/分卷）判断建构方式：时间叙事、并列反驳、还是层层收紧。
4. 找一个**铰链**：论证或叙事改变对象、尺度、语气的位置。给出页码/节号。

产出：作者的问题（一句话，不是主题词）/ 建构（段落群各做什么、在哪里转）/ 入口（一小时从哪读）/ 未读处的猜测（标明）。

常见失败：逐段复述。通览给结构，不给内容。

## 二 · 重构（reconstruct）

把文本还原成**一次解题**：起点困难是什么、作者引入哪个概念/区分、这个选择让他能做什么、又被迫接受什么。

1. 找到困难第一次被说出的地方（常是反问、反例、日常说法）。
2. 追概念出现的位置：关键术语第一次出现在哪段？它取代了哪个旧词？**用词改变处就是选择发生处**。
3. 找承重点（删掉就没有后续结论的那段），整段读完。
4. 标记让步与转折（「然而」「即便如此」「就算承认」及其原文对应词），看作者如何把对方的强处转成自己的推进。

产出顺序：困难 → 选择 → 代价 → 落点。不要写成三行提纲，要写成有定位符的说明。
代价一栏不可省：这个选择让哪些问题变得更难回答，作者处理了吗。

纪律：
- 不要用「作者认为……」滑过去。说得出在第几段认为。
- 不要替作者补完他没写的论证。有跳跃就写「从 A 到 B 缺一步，缺的是哪一步」。
- 文本的叙述顺序 ≠ 作者达到结论的顺序；声明你在重构哪一种。
- 好的重构让读者想回到某一页，而不是点头称是。

## 三 · 前提与缺席（presuppose）

问：这份文本把什么当作不言自明？谁没被提到？它的答案预设了怎样的世界？若该预设不成立，结论会怎样变形？

1. 标记「当然」「自然」「众所周知」「必须」「人人都」及其原文对应词。
   前提常在这些地方一闪而过，却承着整段论证。
2. 谁在场、谁缺席：它讨论谁的选择，略过谁的选择？是疏忽，还是问题设定本身排除了他们？
3. 找一个被摆成「非此即彼」的情境：什么理由排除了第三选项？该理由站得住吗？
4. 作者把什么当作「问题已解决」的标志？这个标志对谁成立？
5. 找「答非所问」的段落：某个回答更契合另一个问题。把它真正在回答的问题写出来。

产出：被当作自然的三项（各带位置与判据）/ 抽掉它会垮哪一部分（具体到段）/ 打开与关闭了哪些问法 / 缺席者及其对结论射程的限制 / 由此自然引出的新问题（不凑数）。

纪律：
- 质疑前提不是驳倒作者。说清**这个前提在干什么活**。
- 不要用「那个时代就是这样」解释一切——那只是把前提重说一遍。
- 区分作者明说的前提与结构暴露的前提；后者是你的读法，必须标为读法。

### 从沉默到假设

找到缺席之后，不要停在「作者没提 X」。停在那里只是抱怨。往前走一步，把它写成可检验的假设：

- 若这里的沉默是问题设定造成的，那么换一个设定，这份材料会不会自己补上这块？
- 若沉默是记录制度造成的，那么同一套记录里有没有别的事件留下了痕迹？（有痕迹才有信息量）
- 若沉默是作者的选择，那么他在别处对同类问题的处理是否一致？

每条写成 `hypothesis / would_show / would_break` 三行，交红队那条线处理，见 `05-red-team.md`。

## 四 · 比较（compare）

比较不是并排放摘要。说清**在哪一层可比**、从哪一步分开、分歧来自材料、概念还是问题本身。

1. 先各自读准：中心问题、关键概念、结论。此时先不找相似。
2. 找真正的对应点：对**同一个问题**给出不同答案的两句话。
3. 找**最早的分歧点**，不是结论不同处，而是从此不同的那一步：前提不同？对象不同？同一个词在两处指不同东西？
4. 检查不可比：若两者根本不在回答同一问题，说出来，不要硬拼。
5. 检查一方是否在**读**另一方：若是，它们不是同一层的两方，而是文本与对它的读法——问读法取走了什么、改了什么，并核对它说文本说了什么。

产出：共享结构 / 概念的对应与滑动（点出同形异义的那个词）/ 分歧起点（两侧都带定位符）/ 保留分歧（若两种读法都成立，给出各自成立的条件）/ 接下来值得重读的问题。

纪律：
- 给两边同样篇幅不是公平。重量应落在它们相交处。
- 不为统一而抹平差异，不为显得深刻而制造对立。
- 当几条读法的一致性恰好等于「通常的读法」时，那是共享习惯，不是独立印证。

## 账本格式（阅读产物）

```
text: <作者《题名》版本/卷次>
method: overview | reconstruct | presuppose | compare
finding: <一句>
type: fact | inference | interpretation | normative
locator: <页/段/行/节>
wager: <作者在此赌什么>
receipt: <我的推断链>
uncertain: <只凭标题/结构得出的判断，标出来>
```

一本书读完，账本应是 8–20 条 finding，而不是 30 页摘录。
