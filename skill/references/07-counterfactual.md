# 07 · 反事实与架空推演

反事实不是「随便改一下看看」。它是一条**受史料约束的推理**：改动必须小到史实仍能承重，后果必须大到值得推演。

## 一 · 合法性条件（不满足就别写）

1. **真分叉**：分支点上，当事人确实考虑过另一选项，或有制度上可行的替代路径。
   证据形态：会议记录里的备选方案、参谋本部的另一份计划、被否决的提案、当事人书信里的犹豫。
   没有这种证据的「如果」，是虚构，不是反事实——**虚构可以写，但要标为 fiction**。
2. **最小改写**：只改一个变量（一个决定、一次战役结果、一个人的生死、一条条约条款），其余保持史料支持的状态。
   改两个以上，你就失去了判断因果归属的能力。
3. **后果可推**：改动的传播路径能被说出（市场、财政、联盟、信息、人力、舆论），而不是「于是历史不同了」。

## 二 · 分支点的选择

优先选：**决策临界点**（有据可查的犹豫）、**信息不对称点**（一方本可以知道而不知道）、**资源约束点**（补给、兵力、贷款到期）。
避免选：纯粹的自然偶然（天气、疾病）——除非你能证明当时人对此有应对方案且方案被否决。

给每个分支点写三行：
```
point: <时点 + 具体决定>
evidence: <证明这是真分叉的材料 + 定位符>
alternative: <另一选项，谁主张过，需要什么条件才可能被采纳>
```

## 三 · 六道约束检验（架空设定的真正骨架）

任何改动都要过这六道，过不了的后果就是空想：

| 约束 | 检验问题 | 常见错误 |
|---|---|---|
| 交通与通信 | 消息从 A 到 B 要几天？命令下达再反馈要多久？ | 用电话时代的速度写驿站时代 |
| 财政汲取 | 谁收税、收什么、收得上来吗？战争靠债还是靠铸币？ | 无成本地养大军、无通胀地印钱 |
| 人力与后勤 | 兵从哪来、粮从哪来、马料从哪来、伤病怎么办？ | 忽略疫病与逃亡率 |
| 制度惯性 | 官僚会执行吗？地方精英会配合吗？既得利益是谁？ | 把改革当命令 |
| 地理与季节 | 道路、河流、山口、港口、雨季与封冻 | 忽略战役的季节窗口 |
| 语言与识字 | 谁能读文件、谁能做统计、方言与标准语 | 让前现代政权做精确人口普查 |

**每条后果都要挂一道约束。** 挂不上约束的后果，写成「可能」，并说明为什么无法约束检验。

## 四 · 二阶与三阶效应

一阶：直接军事/政治后果。
二阶：财政、同盟、市场、舆论、继承、官僚人事。
三阶：制度变迁、思想潮流、人口结构、国际体系。

推演要求：**至少推到二阶**，并且写出「谁受益、谁受损、谁有能力反抗」。
反事实最常见的破产处不是一阶想错，而是忘了受损者的反应。

## 五 · 强度刻度（每个结论都要标）

- `plausible`：分支点有据，约束全过，二阶效应有材料类比
- `possible`：分支点有据，约束部分过，二阶效应为推论
- `implausible`：需要多项同时改变，或违反硬约束
- `fiction`：无史料支撑的设定性改写（架空本身，合法，但须标明）

## 六 · 五种必查的谬误

1. **全知行动者**：让当事人知道后世才知道的信息。
2. **单一变量幻觉**：改一件事却假定其他一切不变（尤其对手的反应）。
3. **回溯决定论**：因为结果发生了，就说它必然发生。
4. **技术决定论**：新发明自动扩散、自动生效、无需维护与配套。
5. **道德账本简化**：把后果算成净收益，忽略谁承担了成本。

## 七 · 情景报告结构

```
# 情景：<一句话>
## 分支点（point / evidence / alternative）
## 改动（最小改写，写清改了什么、没改什么）
## 传播机制（信息 → 决策 → 资源 → 行动，逐环）
## 一阶后果
## 二阶后果（财政/同盟/市场/舆论/人事）
## 三阶后果（制度/思想/人口/体系）
## 约束检验表（六道，逐道写「过/不过/无法判定」）
## 受益者与受损者，以及受损者的反抗能力
## 与现实史的偏离清单（哪一年起彻底分道）
## 置信度（plausible / possible / implausible / fiction）
## 证伪条件（什么材料会让这个情景不成立）
## 来源
```

**与现实史分道的那一年要写出来。** 不写，读者无法判断这是推演还是改写。
