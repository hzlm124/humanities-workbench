# 15 · 概念史先行

中文里大量抽象词是泊来词。**你在用别人翻译过来的范畴思考，而翻译本身带着立场。**
所以任何涉及关键术语的研究，第一步不是找材料，而是查这个词什么时候进来、从哪条路径进来、谁改写过它。

这一册对应 `profile/rules.md` R8。方法取径：科塞勒克（Begriffsgeschichte）的概念史、阿尔都塞的「问题式」、
以及中文语境特有的**和制汉语 / 传教士译词 / 苏俄中转**三条路径。

## 1. 为什么必须先做

- 同一个词在不同年代指不同东西，用今天的词义读旧文本＝时代错置。
- 词义的替换往往**先于**制度变化：概念被改写，制度变化才有合法性语言。这正是领导权分析的前哨。
- 中文的抽象词多数经过一次或两次翻译，每一次都有人做选择：
  `concept → 英/法/德 → 日译 → 中译` 或 `→ 俄译 → 中译`。每跳一次，外延就偏一次。

## 2. 六步流程

**第 1 步 · 定位词**
列出研究里承重的 5–10 个术语（不是所有词）。判据：删掉它，论证会垮。

**第 2 步 · 查词源与转译路径**
- 原文词是什么（英/法/德/俄/日），首次进入汉语的时间与文献；
- 走的是哪条路径：明末清初传教士译词 / 明治日本「和制汉语」/ 清末民初留日学生 / 五四后经俄语或英语 / 1980 年代后经英语重译；
- 谁造的这个词，当时为了对译什么，排除了哪些旧词（例：`economy` 曾译「计学」「理财学」，最后「经济」胜出——胜出本身就是一次选择）。

**第 3 步 · 编年（关键年份表）**
每次语义转折记一行：年份 / 文本与作者 / 旧义 → 新义 / 谁受益。转折点常出现在：译介高潮、政治运动、教科书改写、词典修订。

**第 4 步 · 对比原文外延**
把中文词的当代用法，与原文词在源语言中的用法并置。错位通常在三个地方：
外延宽窄（中文更宽/更窄）、褒贬色彩、是否被附加了道德含义。

**第 5 步 · 画外延变化表**

```
| 术语 | 年代 | 文本/作者 | 所指 | 与原文的偏差 | 谁在推动 |
|---|---|---|---|---|---|
```

**第 6 步 · 连到制度与利益**
词义变化之后，哪项制度随之变化？谁因此获得正当性？**答不出这两问，概念史就只是词源学。**

## 3. 三条中文特有路径

**（a）和制汉语**
社会、经济、政治、革命、文化、哲学、主观、客观、科学、干部、阶级、生产力、生产关系、意识形态——
多数是明治日本为翻译西方概念所造，再回传汉字文化圈。用它们讨论古典文本时，先确认原作者是否用过同一个词、指同一件事。

**（b）传教士译词 vs 和制译词的竞争**
严复一系（「计学」「群学」「名学」）多半败给和制词（「经济学」「社会学」「逻辑学」）。
败因不只是译得好坏，还有教育制度、教科书市场与留学路径。

**（c）借道第三种语言**
「哲学」「美学」「形而上学」等词先由德语或希腊语进入日语，再回传汉字圈；「浪漫」经日语定型后又与英语 romantic 并行。
中转语言的义域会在两次转写中被截断一次，于是同一个原词在中文里的默认联想，往往比原文窄或宽。
查法：找到中转语的那一版译词，比较它的搭配词，再看中文定型时丢掉了哪一层。

## 4. 词义滑动的识别技巧

- **搭配词**：同一词跟哪些动词/形容词共现（「推进现代化」「实现现代化」），搭配变化暴露所指变化。
- **反义词**：一个词的反义词换了，它的含义就变了（「科学」的反义词曾是「迷信」，后来常被换成「不科学」或「伪科学」）。
- **上下位**：它被放进哪个分类体系（「市场」是「机制」还是「制度」？前者可工具化，后者是生产关系）。
- **同义替换**：同一文本里两词并用时，注意何时换用（「管理」→「治理」；「效率」→「效能」），换用点通常对应责任主体或评价标准的变化。

## 5. 已知的典型误译（当案例用，不要当清单背）

| 中文定型 | 原文 | 偏差 |
|---|---|---|
| 多元决定 | surdétermination（overdetermination） | 应为「过度决定」；「多元」暗示并列因素，丢掉「诸层次互相决定、经济最终决定但从不单独出场」 |
| 市民社会 | bürgerliche Gesellschaft / civil society | 黑格尔处兼含「资产阶级社会」，中译常只剩「市民」 |
| 自由 | liberty / freedom / Freiheit | 消极/积极之分在中文常被抹平 |
| 意识形态 | idéologie / ideology | 拿破仑时期的贬义、马克思的批判义、阿尔都塞的中性义，三层混用 |
| 阶级 | class / Klasse | 分析范畴 vs 身份标签，中文日常用法偏后者 |

## 6. 输出：概念史档案

```
# 概念史：<术语>
## 原文与路径
## 关键年份表
## 外延变化（含与原文的偏差）
## 制度连带（词义变化后哪项制度随之变化）
## 受益者（谁获得正当性）
## 本研究中的用法声明（本报告用哪一义，为什么）
```

最后一节不可省：**声明你在本报告里用哪一义**，否则读者无法判断你的论证在哪个概念上进行。

## 7. 与研究流程的接口

- 阶段 0 框定：先做 1–2 个承重术语的概念史，再写断言清单。
- 阶段 2 综合：检查各卡是否在同一义上使用同一词。
- 阶段 3 红队：专查「概念滑动」类问题（kind: concept）。
- 交付：术语表 + 概念史档案作为附录，不进正文。
