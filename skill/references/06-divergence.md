# 06 · 分歧审查：未取之路与缺口

红队问「你错在哪」，你问「你没走哪条路、你漏了什么」。
这是两种不同的失明：一种是**疏漏**（本线自己能补），一种是**问题式不允许被看见**（要换前提才能看见）。
分开它们，是这一步的全部价值。

## 两类产出

### A. 未取之路（possibility not taken）

结论做了一串选择，每个选择都换来一些、也放弃一些。把被放弃的和从未被选择的都挖出来：

- 别的假设/解释（同一批材料的另一种因果结构）
- 别的方法（量化 vs 档案细读；过程追踪 vs 比较历史）
- 别的理论框架与概念（韦伯式 vs 马克思主义 vs 福柯式 vs 施米特式 vs 全球史）
- 别的视角与立场（被统治者的、殖民地的、女性的、边缘群体的、敌对国家的）
- 别的情景（反事实分支）
- 别的读法（症候阅读、隐微阅读、接受史）
- 别的分解方式（按制度 / 按行动者 / 按事件 / 按话语）
- 对**问题本身**的批判（谱系学：这个问题何时、为何被这样问；意识形态批判：它预设了什么）

**判据**：未取之路必须与结论**不能并存**——它依赖另一个前提，或把答案带到本线去不了的地方。
同一前提下换一批材料、加一个案例，那是缺口，不是另一条路。

每条要写：
```
proposal: <一句话>
premise: <它依赖什么前提 / 与结论的哪个前提冲突>
stakes: <若它成立，答案的哪一处会变，怎么变>
research: <验证它需要什么研究（材料 + 方法 + 大致工作量）>
gap: false
```

### B. 缺口（gap）

任何回答这个问题都必须补、而结论没补的东西。标 `gap: true`，并写清：
缺什么（材料族/行动者/时期/语言/机制环节）、为什么必须、补了之后可能改变哪一句。

缺口回本节点补，**不得下传给后续分支**。

## 挖掘方法：从预设入手

不审判，只考古。逐项问：结论把什么当成给定？

- **概念与范畴**：哪些分类被当作自然种类？（「民族」「经济」「宗教」「国家」在何时成为分析单位）
- **分析单位**：为什么以国家/个人/阶级为单位？换单位会看到什么？
- **时间框架**：为什么从这个事件开始、到那个事件结束？谁的时间被当作标准时间？
- **立场**：它从谁的位置说话？谁被当作默认主体？
- **证据资格**：什么被算作证据？谁授权了这种算法（学科、档案制度、国家统计）？
- **价值前提**：哪些「应当」被包装成「是」？
- **接受的看法**：把文献共识当成世界的事实——共识是关于学界的事实，不是关于世界的事实。问：谁的共识、何时形成、基于什么材料、排除了什么。

## 四条经典入口（能用则用，不作为标签）

- **能指滑动**：关键词在材料里、在文献里、在结论里的所指已经错开。
- **知识型/谱系**：什么使某类陈述成为可接受的知识？这套档案制度、学科分类、统计范畴本身可以成为对象。
- **悬置**：先不假定对象如其所名地存在，描述它在材料中如何被构成。
- **解构继承概念**：把概念拆回它当初要回答的经验与问题；把被呈现为必然/自然的东西读成处境与选择——谁的选择、排除了什么。

## 输出格式

一个文件：提案列表 + 一段**总体判断**（这条结论最深的预设是哪一个，若它不成立，问题会变成什么）。
不要在这里重复红队的纠错工作；不要为显得深刻而制造对立；**每条提案都要真的能改变答案**，否则删掉。
